# species-sitecode-merger
Jupyter Notebook (Python) for attaching species/feature data from a CSV/Excel file to geospatial GIS files (SHP/GPKG).

Developed to assist the ERM Offshore wind team during consulting work, automating the previous manual task of finding species for each sitecode. This script will attach endangered species to each sitecode. It is reliable and has been stress-tested on huge datasheets such as EU Natura 2000, with a 1.3GB geospatial data file.

I have added a small, publicly available Species datasheet and Geospatial Data file for test use.
